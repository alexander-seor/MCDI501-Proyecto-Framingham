# MCDI501 - Estadística Computacional para la Toma de Decisiones

Repositorio personal del proyecto desarrollado para la asignatura Estadística Computacional

## Dataset seleccionado

Se utilizará el dataset **Framingham Heart Study**, orientado al análisis del riesgo de desarrollar enfermedad coronaria durante los próximos diez años.

## Objetivo general

Aplicar técnicas de estadística descriptiva, inferencia y modelamiento para estudiar factores asociados con el riesgo cardiovascular.

## Estructura del proyecto

- `fase-1/`: selección, descripción y justificación del dataset.
- `fase-2/`: desarrollo de la Sumativa 1.
- `fase-3/`: desarrollo de la Sumativa 2.
- `fase-4/`: desarrollo de la Sumativa 3.

## Entorno de trabajo

El proyecto utiliza Python y JupyterLab. Las dependencias están registradas en `requirements.txt`.
